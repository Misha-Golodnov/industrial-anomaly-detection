ASHRAE RP-1043: обучение и проверка TEP-комбинации¶

В этом ноутбуке рассматриваем модель из итоговой сборки 03_fused_index.ipynb, адаптированную для датасета ASHRAE. Содержание: загрузка датасета, разбиение на окна, разбиение нормы, стандартизация, обучение, калибровка порога, оценка 28 файлов неисправностей, таблицы и графики. Сборка модели совпадает с итоговой сборкой

Используется существующий код исследовательской ветки:

  • prepare_ashrae_public.py - загрузка зафиксированной CSV-копии;
  • data.ashrae.chiller_windows, normal_split, ChillerWindows - окна и разбиения;
  • CanonicalVariateIndex, WindowMomentIndex, SlowFeatureIndex, TailMax, WithinRunEWMA - готовые компоненты модели;
  • contiguous_groups - границы непрерывных последовательностей;
  • run_ashrae_benchmark.empirical_threshold, metrics - порог и метрики ASHRAE.

Новые реализации детекторов и новое обучение вспомогательных моделей не добавлены. Две небольшие функции ниже только масштабируют ASHRAE-окна и согласуют их метаданные с WithinRunEWMA.score_batch.

1. Настройки эксперимента¶

HELD_OUT_BAND=None - блоковое разбиение с присутствием разных температурных полос в обучении. Установить HELD_OUT_BAND=50, чтобы проверить новый режим: полоса 50 °F будет исключена из fit/reference/calibration и оставлена для test. Разбиение задаётся существующей normal_split, а не случайным перемешиванием окон.

Длина 48 и шаг 6 соответствуют поздней проверке переноса. Уставки 40/45/50 °F не являются полным набором эксплуатационных режимов. При изменении настроек результат станет новым экспериментом, его не следует автоматически приравнивать к историческим таблицам. Пять seeds можно исследовать отдельными последовательными запусками, меняя SEED; по умолчанию выполняется один запуск.

3. Временные окна и разделение нормальных данных¶

chiller_windows выбирает 26 каналов, отбрасывает нерабочие/невалидные точки, нарезает окна внутри блоков и температурных полос. Окно не пересекает удалённую строку. Блок - 180 исходных строк, на краях отбрасывается по 12 строк.

normal_split отделяет fit, reference, calibration и test. Reference сохраняется для совместимости с историческим протоколом, но именно этой TEP-сборке не нужен: компоненты, хвостовые масштабы и центр/std EWMA оцениваются по fit, порог - по calibration. Reference не присоединяется к fit. Неисправные файлы при обучении и подборе порога не используются.

4. Стандартизация и согласование метаданных¶

Как в историческом ASHRAE-transfer, StandardScaler обучается только на отсчётах fit-окон. Перекрывающиеся окна дают повторные вхождения некоторых обучающих строк; это соответствует сохранённому эксперименту и не переносит test-данные в fit.

WithinRunEWMA.score_batch ожидает simulation_run и sample_end. У ASHRAE вместо них — блоки и номера исходных строк. Адаптер ниже использует contiguous_groups: каждый непрерывный участок становится отдельной последовательностью, а row_end передаётся как sample_end. Это технические идентификаторы участков, не независимые физические прогоны. Само сглаживание выполняет существующий WithinRunEWMA.

t0 = perf_counter()
scaler = StandardScaler().fit(parts["fit"].X.reshape(-1, len(CHANNELS)))


def scaled_windows(batch):
    values = scaler.transform(batch.X.reshape(-1, len(CHANNELS)))
    return values.reshape(batch.X.shape).astype(np.float32)


def score_chiller(model, batch):
    groups = contiguous_groups(batch.meta, stride=STRIDE)
    sequence_ids = np.empty(len(batch.X), dtype=np.int64)
    for sequence_id, indices in enumerate(groups):
        sequence_ids[indices] = sequence_id
    meta = batch.meta.assign(
        simulation_run=sequence_ids,
        sample_end=batch.meta.row_end.to_numpy(),
    )
    adapted = ChillerWindows(scaled_windows(batch), meta)
    return model.score_batch(adapted)

5. Обучение TEP-комбинации на норме ASHRAE¶

Используется тот же набор классов, что и в третьем ноутбуке. CVA оценивает связи половин окна, Moments — средние/std, Slow Features — медленные нормальные связи. TailMax объединяет нормированные скоры, EWMA сглаживает итоговый скор с λ=0.2. Это статистические оценки и линейная алгебра, обучение по эпохам здесь отсутствует.

alpha=0.01 внутри компонентов и TailMax задаёт хвостовые масштабы по обучающей норме. Он не равен эксплуатационному TARGET_FPR: окончательный порог отдельно выбирается по calibration после EWMA. Все параметры фиксируются до оценки отказов.

6. Калибровка и проверка на нормальном test¶

Повторно используется ASHRAE-калибратор: тревога при score > threshold. Calibration и normal test оцениваются отдельно; порог не подстраивается по test. normal_fpr — доля ложных окон. normal_block_alarm_rate — доля искусственных блоков хотя бы с одной тревогой. Эти показатели не взаимозаменяемы.

Из-за зависимости окон и смены режима фактическая test-FPR может превышать номинал. Ни окно, ни искусственный блок не являются независимой повторной экспериментальной кампанией. Точная задержка обнаружения в минутах для этой копии не вычисляется.

7. Проверка всех семи неисправностей на четырёх уровнях¶

Теперь, после обучения и фиксации порога, открываются 28 неисправных файлов. SL1 — слабый уровень, SL4 — сильный; одинаковый номер уровня не означает одинаковый физический процент воздействия для разных неисправностей. При holdout-режиме в тест допускается только выбранная температурная полоса.

Из существующей metrics берутся AUROC, balanced AP, recall и normal FPR. Balanced AP рассчитана при искусственных весах normal/fault 50/50 и не равна precision в реальной эксплуатации с редкими отказами. Дополнительно используется стандартизованная pAUC@5% из sklearn (случайный уровень 0.5).

10. Вывод¶

Подход, разработанный на TEP, работает на ASHRAE избирательно: одни слабые неисправности он различает хорошо, другие значительно хуже.

Загрязнение конденсатора и снижение расходов воды хорошо отделяются от нормы. Неконденсирующиеся газы также обнаруживаются достаточно уверенно. Избыток масла сложнее: повышение полноты требует больше ложных тревог. Для слабой утечки и избыточной заправки хладагентом разделение недостаточное.

Одним снижением порога проблему полностью не решить: оно увеличит чувствительность, но одновременно повысит число ложных тревог.
